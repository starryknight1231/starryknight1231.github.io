面试要点
NFA vs DFA：NFA 同一字符可能有多条出路（需要记录状态集合 / 回溯），DFA 每步只有唯一去向。
Thompson 构造法：任何正则都能在 O(n) 时间构造成等价 NFA，状态数 O(n) —— 本页画的图就是它。
JS / Java / Python 的正则引擎是「带回溯的 NFA」：功能强（支持前瞻、反向引用）但最坏指数时间；
  这就是灾难性回溯 (a+)+b 对 "aaaaaaaaaaaaaaaaX" 卡死的根源。RE2 / Rust regex 用 DFA 保证线性。
贪婪与懒惰：* 默认贪婪（尽量多吃），加 ? 变懒惰（尽量少吃）—— 在模拟器里把光标停在分支处就能看到它先走哪条边。
前瞻 (?=) 是零宽断言：不消耗字符，只「看一眼」—— 模拟时注意它的边不会前进输入指针。
