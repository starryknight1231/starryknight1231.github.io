# DevBox · 开发者工具箱

一个纯前端的开发者工具箱，**所有处理均在浏览器本地完成**，无后端、无数据上传、零依赖（不依赖任何第三方库或构建工具）。

## 工具列表（16 个）

| 分类 | 工具 |
|------|------|
| 编码解码 | JSON 格式化（含错误定位）、Base64 编解码（含文件转 Data URI）、URL 编解码、HTML 实体编解码、JWT 解码 |
| 转换 | 时间戳转换（自动识别秒/毫秒）、进制转换（支持 BigInt 大数）、颜色转换（HEX/RGB/HSL + 色阶） |
| 文本 | 文本处理与统计、Markdown 预览（内置迷你渲染器）、中文占位文生成 |
| 生成器 | UUID v4、SHA 哈希计算、密码生成（含熵值强度） |
| Web | 正则测试（高亮 + 捕获组 + 替换）、HTTP 状态码速查 |

## 本地运行

无需构建，任选其一：

```bash
# 直接双击 index.html 用浏览器打开即可

# 或起一个静态服务
python3 -m http.server 8123
# 然后访问 http://localhost:8123
```

> 哈希工具依赖 WebCrypto，需通过 `http://localhost` 或 `https://` 访问才可用（现代浏览器将 `localhost` 与 `file://` 视为安全上下文，一般无碍）。

## 特性

- 深色主题，快捷键 `/` 聚焦搜索
- 工具可通过 URL 直达：`index.html#/json`、`#/regex`、`#/timestamp` …
- 记住上次使用的工具
- 所有输出块一键复制
